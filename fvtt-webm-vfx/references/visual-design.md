# 视觉设计与原语

## 目标

把“看起来像什么”和“怎么动”拆开。FVTT 平面 VFX 的辨识度通常首先来自投影轮廓、负空间、峰值帧和运动方向，其次才是粒子数量和辉光强度。

## 载体选择

| 需求 | 首选原语 | 典型参数 |
| --- | --- | --- |
| 剑气、弯月、横斩 | `arc_slash` | 圆心、半径、起止角、线宽、拖尾长度、展开曲线 |
| 闪电、电击、链状能量 | `lightning` | 起终点、分段、抖动、分叉、核心线宽、闪烁 |
| 激光、射线、吐息骨架 | `beam` | 起终点、宽度、脉冲、核心/外辉光、火花 |
| 爆炸、命中、神圣闪光 | `burst` + `particles` | 核心半径、放射线、粒子速度、淡出 |
| 法阵、冲击波、光环 | `ring` | 半径曲线、环宽、旋转/脉冲、循环 |
| 火花、碎屑、星点 | `particles` | 发射窗口、速度、角度、寿命、尺寸、重力 |
| 吸引、坍缩、重力井 | `converge` + `ring` | 初始环带、收束半径、旋涡角、拖线、内缩环 |
| 烟尘、毒雾、阴影残留 | `smoke` | 团簇数、漂移、膨胀、模糊、寿命 |
| 特殊纹章、兽首、幽灵 | `sprite` + 程序层 | 单张透明素材、位置/缩放/旋转曲线、辉光、遮罩 |

复杂效果应组合少量职责明确的层。一个高质量斩击常见结构是：暗色主体弧 + 明亮窄核心 + 少量尾随粒子；不需要把每一种原语都叠上去。

## 时序

爆发效果常用三段：快速建立、短暂峰值、较长余韵。把峰值安排在总时长约 20%–45% 处通常容易读清，但这只是设计起点，不是固定规则。命中闪光的建立可极短，烟雾余韵可更长。

持续循环效果必须把“循环运动”和“进入/退出动画”分开。素材本体应可以循环；FVTT/Sequencer 负责开始时淡入、结束时淡出时，不必把一次性的进入/退出烘焙到循环视频中。

## 亮度结构

至少区分主体、中间亮层和局部核心。不要把整片主体都做成同样高亮。程序化 Glow 只负责扩散已经存在的亮部，不能替代主体造型。

建议先在没有强 Glow 的情况下确认轮廓可读，再增加辉光。透明素材在黑色场景上和明亮地图上都要有可辨识结构；纯加法白光在浅色地图上容易消失。

## 方向与画布

定向效果默认左到右。主体尽量围绕画布中心布置，同时在四边留至少约 5% 安全区；扩散烟雾和长尾迹可以更接近边缘，但不要在峰值阶段裁切关键轮廓。

若最终由 Sequencer 拉伸到起终点，原素材应保持标准长度和稳定宽度，避免视频内部同时做大幅长度缩放造成二次变形。

## 粒子纪律

粒子是辅助信息，不是结构替代品。先做主轮廓，再加粒子。随机必须使用固定种子以便复现和迭代；同一配方在相同 seed 下应该生成相同的宏观结构。
